# Roo v1.6.0 更新说明

## 4 大 UI / UX 改进

按主人反馈重新打磨信息架构和视觉密度。

### 1. NET DIAGNOSTICS 语义清理

之前「当前出口节点：美国-纽约」+ 下一行一个陌生 IP，看着像"节点 = IP"但实际不是。现在明确分三种情况：

- **节点探测成功**：`选中节点 [美国-纽约 · 绿色徽章] / 节点真实出口 IP（地区/ISP）/ <ip+city+isp>`
- **节点探测失败**：`选中节点 [美国-纽约 · 异常] / ⚠ 下方 IP 不是该节点的真实出口，而是 Roo 本机/前置 fallback / <fallback IP>`
- **无选中节点 (direct/global)**：`Roo 代理链路实际出口 / 经 Roo 出口测得的 IP（地区/ISP）/ <ip...>`

所有 IP 都带地区 + ISP 信息，一眼能看明白。

### 2. 前置跳板 UI 紧凑化

原来 4 个占满一行的大 input，改成 **2×2 行内网格**，每格左侧有 `HTTP / HTTPS / ALL / NO` 霓虹标签，不再 4 倍纵向高度：

```
┌ HTTP  │ http://127.0.0.1:6578 ┐  ┌ HTTPS │ http://127.0.0.1:6578 ┐
└───────┴───────────────────────┘  └───────┴───────────────────────┘
┌ ALL   │ socks5://127.0.0.1:6578┐  ┌ NO    │ localhost,127.0.0.1  ┐
└───────┴───────────────────────┘  └───────┴───────────────────────┘

[⇔ 一键同步]  [清空全部]              [重置] [保存前置跳板]
```

- **⇔ 一键同步**：把 HTTP 行的地址复制到 HTTPS / ALL（ALL 自动改 socks5:// 前缀）
- **清空全部**：一秒清四行

### 3. 出口节点池：测延时 + 权重说明

- 表头新增 **「延时」列**
- 表格每行新增 **「⚡ 测」按钮**，顶部新增 **「⚡ 全部测延时」** 按钮
- 延时颜色分级：`<500ms 绿 · <1500ms 黄 · ≥1500ms 红`
- 测试结果带 tooltip 显示实际出口 IP
- 卡片顶部说明文案 **明确权重语义**：
  > 权重：加权策略下数字越大被选概率越大（如 A=1、B=3 → B 被选概率是 A 的 3 倍）；轮询/随机策略下权重字段被忽略。

### 4. chain + rules 两 tab 合并为一个 CONFIG

顶栏瘦身：`01 CONSOLE / 02 CHAIN / 03 RULES / 04 LOGS` → `01 CONSOLE / 02 CONFIG / 03 LOGS`

CONFIG tab 顶部有一条 **sticky 子导航栏**（斜切按钮风格）：

```
[流量模式] [路由策略] [系统代理] [前置跳板] [出口节点池] [分流规则]
```

点击 → 平滑滚动到对应卡片；顶部始终保留 80px 偏移保证不被子导航遮住。
